PUBLIC KEY INFRASTRUCTURE (PKI)

PKI certificate & secure communication

Local Root CA signs the server certificate (RSA-3072). Simulate a full PKI secure transmission: certificate verification, RSA-OAEP session key wrapping, AES-256-GCM encrypted payload, and RSA-SHA256 signed receipt.
